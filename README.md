# Ruang Belajar UKOM

Materi 6 bab dan 600 soal latihan untuk Uji Kompetensi Teknis (UKOM) pengisian jabatan fungsional DJP 2026, dalam satu halaman HTML statis.

- `index.html` adalah seluruh aplikasinya (tanpa build step).
- Progres tidak tersimpan otomatis; gunakan tombol **Simpan** untuk membuat kode, lalu **Masukkan kode** untuk melanjutkan.

Deploy: Vercel, preset "Other", tanpa build command, output directory root.
